## Kontroll av strömförbrukning och miljöpåverkan

I katalogen `stats` finns filen `energy_usage.md` som innehåller exempel på statistik 
för strömförbrukning och uppskattad klimatpåverkan. Fyll på filen med 
verkliga värden när du har mätdata.

Exempel på mätpunkter som kan följas:

- CPU- och minnesanvändning
- Uppskattad effektförbrukning (i Watt)
- Beräknad koldioxidpåverkan

Använd ett verktyg för energimätning på din dator för att uppdatera filen regelbundet.
